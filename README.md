# 印象簿（Impression Book）

MaiBot 插件：让 Bot 全局识别每位群成员，为每个人维护好感度与印象条目，并在对话中按需把"对 Ta 的印象"注入聊天上下文——Bot 会记得谁是谁。

## 功能

- **全局成员档案**：以 QQ 号为唯一身份，跨群合并；首次发言自动建档，昵称、群名片、活跃度自动更新
- **好感度体系**：0-100 数值 + 六档亲密等级（陌生/相识/熟悉/朋友/好友/挚友），阈值可在配置中调整
- **Bot 自动评估**：按发言积累自动调用 LLM 评估态度变化，微调好感度并提炼新印象（可调节频率与冷却）
- **主人手动管理**：通过 QQ 号认证的主人有完整管理指令，随时改印象、调好感
- **向量检索**：印象条目经嵌入模型向量化，按当前消息语义检索相关条目
- **上下文注入**：提到 Bot 名字或私聊时，把印象卡注入聊天上下文，让 Bot 的回复带上对对方的认知
- **Bot 名字可改**：配置项 `persona.bot_name`，插件所有文案自动跟随

## 安装

1. 将本插件目录放入 MaiBot 的 `plugins/` 目录，重启 MaiBot。
2. 在 WebUI「插件」页启用并配置：
   - `身份.bot_name`：你的 Bot 名字
   - `主人.owner_qq`：你的 QQ 号（管理指令凭据）
3. 确认宿主模型配置中存在 embedding 任务（向量检索依赖它；未配置时插件会停用向量检索并在日志中明确提示，其余功能不受影响）。

## 指令

所有人可用：

| 指令 | 说明 |
|------|------|
| `/印象` | 查看自己的印象卡 |

主人专属（以配置的 QQ 号认证）：

| 指令 | 说明 |
|------|------|
| `/印象 <QQ号>` | 查看任意成员的印象卡 |
| `/加印象 <QQ号> <内容>` | 追加印象条目（自动向量化） |
| `/改印象 <QQ号> <编号> <内容>` | 修改指定条目，视为主人设定 |
| `/删印象 <QQ号> <编号>` | 删除指定条目 |
| `/好感 <QQ号> <+N/-N/N>` | 增减或直接设定好感度 |
| `/专属 <QQ号> 开/关` | 标记或取消专属用户 |
| `/亲密榜` | 好感度前十排行 |
| `/忘记 <QQ号>` | 删除该成员全部数据 |
| `/印象帮助` | 查看指令帮助 |

## 配置说明

| 配置 | 默认 | 说明 |
|------|------|------|
| `好感度.initial` | 30 | 新成员初始好感度 |
| `好感度.threshold_*` | 10/30/50/70/90 | 五档升级阈值 |
| `检索注入.trigger_mode` | name_or_private | 注入触发方式，另可选 every_message / off |
| `检索注入.top_k` | 3 | 印象卡展示的条目数 |
| `自动评估.enabled` | 开 | Bot 是否自动微调好感度 |
| `自动评估.judge_every_n_messages` | 8 | 每人多少条发言触发一次评估 |
| `自动评估.cooldown_minutes` | 30 | 同一成员评估冷却 |
| `自动评估.model_task` | 空 | 评估所用模型任务名，留空用宿主默认 |
| `自动评估.max_auto_impressions` | 20 | 每人自动印象条目上限 |

## 数据与隐私

- 数据保存在宿主 `data/plugins/github.hvbnm-afk.impression-book/` 下（profiles.json 与 impressions.json），不写入宿主数据库。
- 本插件会为群成员建立画像数据。**公开发布或多人共用时，请在群内公示并取得同意**；`/忘记` 指令可满足成员的数据删除请求。

## 开发与维护

- 改代码后在群内执行 `/pm plugin reload github.hvbnm-afk.impression-book` 热重载。
- 发布前请把 `_manifest.json` 中的 `author`、`id`（建议 `你的名字.impression-book`）与 `urls` 改为自己的信息。
- 版本变更请同步递增 manifest 的 `version` 并更新 CHANGELOG.md。
